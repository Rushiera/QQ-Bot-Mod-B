### 3.2 对比口径（逐条比的键）

**层 1 · 闸门影子（零成本，默认跑）**——同一条候选文本喂两套 `SendQueue`，比**裁决**：

| 键 | 取值 | 归一化 |
|:--|:--|:--|
| `chatKey` | `group:<id>` / `private:<id>` | 原样 |
| `atUserId` | 显式点名目标 / null | 原样（VIP 通道、botguard、rapport 都靠它分流） |
| `verdict` | `allow` / `deny` | deny 再细分类别：`botguard` / `rapport` / `hardLimit` / `quota` / `minute` / `hour`（按错误串首词判；`sender.js:122`、`:141` 与 `:150+` 文案互不重叠） |
| `sentCount` | mock 收到条数 | 数值相等（被拒必须 0） |
| `quotaTimes` / `hardTimes` | 记账长度 | 数值相等（被拒不占配额） |

**层 2 · 端到端影子（按需，验收窗口内跑）**——同一份 WS 事件流 fan-out 两份，比**发言序列**：

| 键 | 取值 | 归一化 |
|:--|:--|:--|
| `chatKey` | 同上 | 原样 |
| `ordinal` | 该 `chatKey` 内第 N 条发言 | 1 起递增（顺序即语义） |
| `norm(text)` | 候选 / 实际文本 | `trim` → 全角转半角 → 去所有空白 → 去 markdown（与 `sender.js:487` `mdToPlain` 同口径） |
| `tsBucket` | `Math.floor(ts / 15000)` | 影子串行重放会晚，放宽到 15s 桶；跨桶即错位 |
| `mid` | 协议端消息 id | **不参与比对**（影子无 mid）；实际侧 `mid===null` 视为发送失败 |

### 3.3 零差异判据（三条全满足才算零差异）

1. **序列相等**：实际发言序列 `[(chatKey, ordinal, norm(text))]` 与影子序列**逐位相等**（含顺序）。
2. **裁决相等**：每条候选的 `verdict`（含 deny 细分类别）两边完全一致——只比放行/拒绝不够，「被硬限拦」与「被配额拦」给模型的错误文案不同，行为也不同。
3. **无孤儿**：`onlyActual = 0` 且 `onlyShadow = 0`。

任一不满足 → 记一条 diff：`{chatKey, ordinal, kind: onlyActual|onlyShadow|verdictDiff|textDiff, actual, shadow}`。**不存在「近似通过」**——`mdToPlain` 归一后仍差一个字即真差异。

### 3.4 7 天观察的统计方式

**每日一行**（`tools/shadow-diff.mjs` 产出，落 `runtime/.shadow/<YYYY-MM-DD>.json`）：

| 列 | 含义 |
|:--|:--|
| `candidates` | 当日进入发送管道的候选条数（S1/S5 截获计数） |
| `actual` | 实际发出条数（S3 `self:true` 且 `mid!==null`） |
| `shadow` | 影子放行条数（S5 mock 计数） |
| `matched` | 三键全等条数 |
| `onlyActual` / `onlyShadow` | 单向多出条数 |
| `verdictDiff` / `textDiff` | 裁决不一致 / 文本归一后仍不同条数（`verdictDiff` 按类别分列） |

**判定规则**：
- **单日零差异** = `onlyActual = onlyShadow = verdictDiff = textDiff = 0` 且 `matched = candidates`。
- **7 天通过** = 连续 7 个自然日均满足单日零差异，且每天 `candidates ≥ 1`——无发言的日子不计入，避免「零流量空过」。
- **回归线**：任一指标 > 0 即当轮报红、关掉影子开关、回层 1 定位（层 1 能把「闸门错」与「发送管道错」分开）。
- **统计口径固定**：先按 `chatKey` 分组再汇总；不按会话文件聚合（轮转会换文件，`store.js:24` `ARCHIVE_DIR`）。

**开关**：影子默认关（配置里一个布尔，读不到即关——失败收紧不放开）。开启只影响进程内一条 fan-out，不改 `_unpack` 任何字节。
