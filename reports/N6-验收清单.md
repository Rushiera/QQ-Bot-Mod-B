## 二、影子观察（默认状态，零风险）

重启后 `ingress.mode='shadow'`——**所有群消息都会过判断器，但一个动作都不执行**，只往 `app/data/metrics/intent-<日期>.jsonl` 落行。

| # | 做什么 | 判据 |
|:--:|:--|:--|
| 1 | 正常在群里聊十几句、派一两个活、要一次回执 | 文件里有行；`kind` 与你直觉一致（派活 = instruct、回执 = instruct/readonly、闲聊 = chat） |
| 2 | 盯 `result` 列 | 全部 `shadow`（出现 `live:*` 说明模式被切了） |
| 3 | 盯 `target` 列 | 点名派活的目标猫对得上（`跟R喵说…` → `R喵`）；对不上就把那几行贴我，我调正则 |

**这一步的价值**：判断器是规则优先 + LLM 兜底，规则层现在只有 6 组正则。真实语料跑一天，就能看出哪类话判错——这是切 live 前的唯一依据。

## 三、逐类切换（影子看顺了再切，随时可退）

**不用改配置、不用重启**——两条 HTTP 就切：

```
POST http://127.0.0.1:3280/api/nav/ingress   {"mode":"live","allow":["readonly","shot"]}
```

| 顺序 | 建议 allow | 切过去之后群里试 | 回退 |
|:--:|:--|:--|:--|
| ① 只读 | `["readonly","shot"]` | 「回执」「各单位运行情况」「截一下 majmordomo 的会话」 | `{"mode":"live","allow":[]}` |
| ② 开关 | `+ "switch"` | 「打开领航员」「可以退出领航员了」 | 同上摘掉 'switch' |
| ③ 生成 | `+ "generate"` | 发张图 +「做成三视图」、「念一下」 | 摘 'generate' |
| ④ 会话 | `+ "session"` | 「清掉 R喵的会话」（轻的）/「重建 X 的前文」（重的，会动别人的前文） | 摘 'session' |
| ⑤ 投递 | `+ "send"` | 「跟R喵说，上工qqbotb」 | 摘 'send' |

**切过去那一刻会发生什么**：业务面自己那套工具壳自动闭嘴（`nav-tools.js` 的 `handedOff` 每 5 秒问一次单体），所以不会双投——但**业务面模型不能再调那些工具了**，群里的识别全靠单体判断器。切之前请确认第 2 步的判定记录是准的。

**回退一句话**：`{"mode":"shadow"}` → 回到「只采集、全靠业务面」。

## 四、拍板项

| # | 事 | 选项 | 我的建议 |
|:--:|:--|:--|:--|
| 1 | 判断器要不要开 LLM 兜底 | `navigator.intent.llm` false（现）/ true | **先 false**。规则层判不动的会落成 `chat`（不投递），比误投安全；等 shadow 记录里看到成批的「应该是指令但判成 chat」再开 |
| 2 | 生成类先切还是后切 | 现在的建议序把 generate 放第 ③ | 生成四件依赖「本群最近一条带图消息」的缓冲——那是我新写的环形缓冲（40 条/群），**没经过真实群验证**，建议至少等第 ① 步顺了再切 |
| 3 | `session`（清会话 / 重建前文）要不要进 live | 进 / 不进 | **最后切**。`nav_reset` 动的是别人的前文，判错不可逆；建议前四类跑稳一两天再动它 |
| 4 | B48 成本看板两条路 | 改 `api.model` 键 / 填 `api.modelPrices` | **都不用**——已按第三条路修完：内置表加 `deepseek-v4.1-flash` 显式条目，`resolveModelPrice` 实测已命中（`source:official`）；远端表 192 条里没有这个名字是因为中转站按 `deepseek-flash` 命名，但内置表兜得住 |
