`tools/prompt-memory-split.mjs`（300 行，纯只读，不 import 业务模块）


**为什么走 --from-file**：`routes.js:751-780` 的 `/api/prompt-preview` 只返回 `{systemPrompt, tools}`，**不含 user 提示**——记忆段在 user 提示里，预览入口拿不到真实快照。故按任务卡兜底选项实现 `--from-file`（会话 json 自动取 `userPrompt`，缺则退 `inputMessages` 最后一条 `role=user`；纯文本原样）。

**分段边界（读源文件，不猜）**

## 二、B48 · 缓存计价折扣率核对

`tools/price-cache-audit.mjs`（319 行，纯只读；**默认不外联**）

```powershell
node --check tools\price-cache-audit.mjs                    # exit 0
node tools\price-cache-audit.mjs                            # 本地配置 + UNVERIFIED
node tools\price-cache-audit.mjs --fetch                    # 真拉远端表
```

三段：只读文本解析 `config.js` 的 `DEFAULT_CONFIG.api`；直读数据根 `_unpack/data/config.json` 的 api 段；从 `config.js:23` / `community.js:7` / `price-feed.js:15-21,49-72` 取 URL 与字段名；③ `--fetch` 才拉，失败明示原因 `exit 1`。

**默认运行实测**

| 键 | 代码默认 | 磁盘实值 |
|:--|--:|--:|
| priceInputPerM / priceOutputPerM / priceCachedPerM | 0 / 0 / 0 | 0 / 0 / 0 |
| useOfficialPrice | true | true |
| api.model | （空） | `deepseek-v4.1-flash` |

→ 打印 `UNVERIFIED（本次未外联取证…折扣率仍属估算）`。

**`--fetch` 取证（2026-10-30 10:58 本机）**：`HTTP 200 · https://kondius.cn/qq-agent/model-prices.json · 80,033 字符 · 192 条（丢弃 0）· 242 ms`。折扣率分布：DeepSeek Flash 系 2.00% · DeepSeek Pro 3.33% · 主流 10%（gpt-5.5 / claude-opus-4.8 / gemini-3.1-pro / kimi-k3）· 12.5%~25%（glm-5.3 / doubao-2.1-pro / qwen3.8-max / grok-4.6）· 无缓存优惠（claude-opus-4.1 / ernie-5.0 / qwen-plus）为 null 按 in 计。

**顺带查出的真问题（比 B48 本身严重）**：当前模型 `deepseek-v4.1-flash` **在 192 条里全不命中**——
- 远端表只有 `deepseek-flash` / `deepseek-v4-flash`；内置表 `model-prices.js` 内也 0 命中（`text-grep` 实测）；
- 前缀匹配 `model-prices.js:315` 只认 `key+'/'|'-'|'@'|':'`，而 `deepseek-v4` 与 `.1-flash` 之间是 `.`，不成立；
- ⇒ `resolveModelPrice` 返回 `source='unmatched'`、单价全 0（`model-prices.js:580-586`），`llm.js:673-676` 乘出成本 = 0。

含义：成本看板不是「估算偏差」，而是**恒 0**——「省了多少」= 两个 0 相减。修法两条（本轮不动，交主干裁）：① `api.model` 改成表内存在的键；② 填 `api.modelPrices['deepseek-v4.1-flash']`（优先级最高，`:549-563`）。走中转时按头注释本应关 `useOfficialPrice` 手填。
