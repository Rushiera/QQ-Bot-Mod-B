# R6-L3 · 用量页后端聚合口径（token 合计 ≠ 按群/按模型求和）

> 线号：R6-L3 · 队列编号：Q-001 · 日期：2026-10-31

> 结论：**修聚合（不是修口径说明）**——根因是「首见组双计」，一处 8 行初始化缺陷，非设计取舍。

验收①达成。**关键反差**：`runs` 与 `cost` 三处全等，只有 token 类不等——这不是「维度展开重复计数」，而是「某几个字段被算了两次」。现象本身就是根因的指纹。

## 二、根因（`app/src/business/app.js:2278`，改前原文）

```js
if (!map.has(key)) map.set(key, { key, ...g, runs: 0, exactCalls: 0, cost: 0 });
const t = map.get(key);
t.cost += Number(g.cost) || 0;
t.peakCost += Number(g.peakCost) || 0;
…
t.totalTokens += Number(g.totalTokens) || 0;
```

- 建桶那一行用 `{ key, ...g }` **把首见组的全部数值字段带进来**，随后同一份值又被下面的 `+=` 累加一次。
- 但 `runs` / `exactCalls` / `cost` 三项**显式写了 0**——所以只有这三项正确，其余 8 个 token/cost 拆分字段全部双计。
- 这正是「cost 与 runs 相等、只有 token 不等」的唯一解释。

### 2.1 定量验证（差额 = 每个 key 首见日的组值之和）

改前实测差额 vs 「首见组值之和」独立复算（`tools/CatTemp/r6l3-rootcause.mjs`）：

| 维度 | 实测差额（求和 − totals） | 首见组值之和 | 是否一致 |
|:--|--:|--:|:--:|
| 按群 | 35,261,046 | **35,261,046** | ✓ 完全一致 |
| 按模型 | 32,953,672 | **32,953,672** | ✓ 完全一致 |

按模型的差额 32,953,672 = `2026-10-26.json` 里 `time.api.freeshare.tech：deepseek-v4.1-flash` 那一行的 `totalTokens`——一个 key 的首见日值。按群的 35,261,046 = 10 个群各自「首次出现那天」的组值相加（8 个群首见 10-26、1 个 10-27、1 个 10-29；逐条明细见复跑脚本输出）。

**这也解释了为什么这个 bug 能存活到 R5**：差额恒等于「每个 key 的首见日值」，只在窗口起点那天发生一次，不随天数增长；而 `cost` / `runs` 恰好被显式归零，页面上看「成本对得上」，很难怀疑 token。

验收②达成，且定位到行：`app/src/business/app.js:2278`。

## 三、修法（已落地）

`app/src/business/app.js:2272-2315`，两处改动：

1. **建桶时数值字段逐个显式归零**（`USAGE_SUM_FIELDS` 11 项 + `hasPeakModel`），只保留 `vendor` / `model` 这类非数值身份字段：

```js
const USAGE_SUM_FIELDS = [
  'cost', 'peakCost', 'offPeakCost', 'peakTokens', 'offPeakTokens',
  'promptTokens', 'completionTokens', 'cachedTokens', 'totalTokens', 'runs', 'exactCalls'
];
if (!map.has(key)) {
  const init = { ...g, key };
  for (const f of USAGE_SUM_FIELDS) init[f] = 0;
  init.hasPeakModel = false;
  map.set(key, init);
}
```

2. **合并后重算派生比率**（`cacheHitRate` / `peakRatio` 不能相加，与 `totals` 的处理口径对齐，`app.js:2307-2311`）——顺带修掉「按群/按模型行的命中率显示的是首见日比率」这个同源缺陷（`app/ui/views/usage.js:348` 直接显示该字段）。

不改聚合结构、不改维度定义、不改前端。前端 `usage.js` 的「口径核对块」会自动全部打成 `=`——契约不变，页面无需改动（`app/ui/**` 本轮禁改，也不需要改）。
